## Installer implementation (MIT)

This repository contains a new, narrowly scoped Python installer written for a
single verified Windows application build. See the root `LICENSE`.

## Not included

No Claude application binaries, Claude-provided English language catalogs, patched
application bundles, user profiles, DeepSeek/API tokens, local backup manifests,
real screenshots, or chat/work files are included. The program merges translation
resources with each user's own installed English catalog at install time.
